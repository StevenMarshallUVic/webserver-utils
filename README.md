# webserver-utils
Utilities for working with proteomics and bioinformatics webservers, programs, and APIs.

## Webservers
### Implemented
Currently included webservers include:
- [BLAST](https://blast.ncbi.nlm.nih.gov/Blast.cgi)
- [Clustal Omega](https://bio.tools/clustalo_ebi)
- [SignalP (6.0)](https://services.healthtech.dtu.dk/services/SignalP-6.0/)
- [UniProt](https://www.uniprot.org/)

### Planned
Planned additions include:
- [AlphaFold Protein Structure Database](https://alphafold.ebi.ac.uk/)
- [NCBI](https://www.ncbi.nlm.nih.gov/)
- [RCSB PDB](https://www.rcsb.org/)

## Requirements
Python 3.15 required due to use of `frozendict`.
